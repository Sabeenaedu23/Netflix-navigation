# Netflix Mobile Navigation 🎬

## 📌 Project Overview

Netflix Mobile Navigation is a front-end project inspired by Netflix's mobile navigation design. It features an animated sliding menu with multiple navigation panels, creating a smooth and interactive user experience.

This project was developed to practice HTML, CSS, and JavaScript concepts.

## ✨ Features

- Netflix-inspired navigation design
- Interactive menu open and close buttons
- Multi-level navigation panels
- Smooth CSS transitions and animations
- Responsive mobile-friendly layout
- JavaScript-based menu interactions

## 🛠️ Technologies Used

- **HTML5** – Structures the navigation menu.
- **CSS3** – Handles styling, transitions, and animations.
- **JavaScript** – Controls menu interactions and navigation visibility.

## 📚 Key Concepts Practiced

- DOM Manipulation
- JavaScript Event Listeners
- CSS Transitions and Animations
- Responsive Web Design
- HTML Structure and CSS Styling

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
